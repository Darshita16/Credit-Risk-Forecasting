## 📖 Overview

This repository contains the solution for the CMPUT 175 assignment: building a loan‐default prediction system using a Decision Tree classifier, and deploying the results via a circular doubly-linked list “carousel.” You will gain hands-on experience with:

- Data preprocessing (missing values, filtering, class imbalance)
- Exploratory analysis (histograms, pie charts)
- Training and evaluating a Decision Tree model (`scikit-learn`)
- Feature scaling (`StandardScaler`)
- Interactive data structures (circular doubly-linked list)
- Simple text-based navigation interface
